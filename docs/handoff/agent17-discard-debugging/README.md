# Agent 17 DISCARD debugging sources (historical)

This is an archival bundle of the four standalone C debugging sources created
during the original DISCARD atomicity and authoritative-map-scan investigation.
They are **not** current production source, integrated test fixtures, or
qualifying evidence. The relevant maintained exact-production-C coverage is
in `tests/runtime/native/mapping/authority.c`,
`tests/runtime/native/mapping/authority-throughput.c`, and
`tests/runtime/native/source-contract-test.py`.

The exact original source files are contained in [sources.tar.gz](sources.tar.gz)
without generated executables:

The archive is a deterministic gzip-compressed tar stream with SHA-256
`2d4ddb8a031ab7c7155920f3d3646720711a9be037142075a6d6b9fa46991724`.
Its Git blob SHA-1 is `c29c26b02d58f0831f38230f6144ec6d4d307123`.

The earlier model returns `-EUCLEAN` after page 0 was invalidated, showing why
validating only physical liveness could not guarantee multi-page atomicity.
The post-fix model returns `-EUCLEAN` with both pages unchanged. These models
**do not independently verify the current kernel implementation**, the live
Device Mapper target, allocator behavior, or actual Linux swap. In particular,
the old source snippets and their "current" comments refer to their inspection
checkpoint, **not** to current `main`.

No binary generated by the local compiler is included. Do not add this archive
to production builds or replace the project-authorized `make test` qualification
with execution of these historical models. The source, module, lifecycle and
physical acceptance gates remain unchanged.
