It does not duplicate or loan an original upstream Linux swap-slot incarnation or public current `dm_table` lifetime. Real original `clone_endio` applies the target `->end_io` status, frees the clone/target I/O, and invokes `dm_io_dec_pending(io,error)` to progress DM original upper I/O. It is not itself a novel zswap-source owner.

Current genuine [product `src/kernel/dm-target.c`](https://github.com/k1moradi/swapz/blob/67cb371f82fb7ea2836f2f9b5c98371c9d3af548/src/kernel/dm-target.c) `swapz_map` rejects invalid 8-sector 4096 full-page geometry and closed admission, then under `ctx->queue_lock` checks `ctx->accepting` a second time and links the **core-delivered clone** to `ctx->incoming` before `DM_MAPIO_SUBMITTED`. The existing normal upper RAW_4096 is always full original UNCOMPRESSED 4096, not upstream STORED LZ4. Current `swapz_async_lower_write_done` stores lower error before notification, enters the same queue lock and completes `inflight->lower_done`, wakes current owner worker, then unlocks. The ordered `swapz_worker_pass` checks `completion_done` before finalization and next admitted wave, and current `swapz_gc_relocate_one` reads the current `ctx->maps[logical]` snapshot and preserves its original encoding; this is NOT a lease for an arbitrary external historical compressed record.

The unique target `swapz_complete` checks terminal error `ctx->failed` before setting clone BIO status and calling **one** `bio_endio(bio)`. The deferred normal ACK list and offloaded completion worker both `bio_list_pop` each owned BIO once before calling this single common completion point. `swapz_try_completion_handoff` serializes handoff under `queue_lock`, gates on `ctx->accepting` and `!failed` and `completion_active` atomic claim, clears the producer's deferred list, and queues one work item. This is source-side evidence for the **existing accepted normal BIO** single-owner ACK protocol, NOT a runtime proof against every maliciously duplicated callback/foreign clone or a genuine external compressed source-to-DM ACK. `swapz_end_io` also forces a terminally failed target's clone status to error before DM completes original I/O. No invented positive first-source authorization.

`swapz_drain` closes admission under `queue_lock`, cancels retention timer, drains preparation and chained ordered workers, waits every pending `lower_done`, checks `completion_active` and nonempty `completion_bios` before `swapz_dtr` frees `ctx` and clears `ti->private`. The original DM `__unbind` removes old table and crosses `dm_sync_table` SRCU barrier; `dm_get_live_table/dm_put_live_table` are NOT exported as a lifetime pin to this external module. No independently created late external source callback is authorized to touch `ti` after teardown, even if recycled old/new target pointers and equal sector/map/extent generation values compare equal.
