## Frozen proposed semantic handshake

- Producer must prove stored zswap entry was previously **accepted** into RAM cache and is now selected by real eviction, not initial rejection or synthetic `bi_swap_origin`; authentic xarray entry/slot generation/epoch and codec-at-store-time from active immutable pool. Precise original 4096-byte SHA256 captured when original bytes available with bounded CPU/RAM overhead; immutable copied compressed LZ4 bytes length **1..3568** and correct CRC32C with above convention; one lifetime/abort/finish, no borrowed zsmalloc pointer.
- Transport must carry **separate compression-aware bytes plus immutable metadata**. Ordinary upper `REQ_OP_WRITE|REQ_SWAP` 4096-byte semantics are unchanged. A genuine transport mechanism must be source-verified through MM/BIO→clone/split/DM and keep one generation-bound owner until consumer durable write publication and upper success. No variable-size compressed payload smuggled via normal `bi_io_vec` or conflation with existing origin scalar. New schema/opaque sideband/typed buffer design requires review and kernel API compatibility; while its integrity is unproved, the transport stays disabled and falls back to *original 4096 decompressed* ordinary path.
- Consumer must only accept explicit `ZSWAP_COMPRESSED_LZ4_V1` **volatile RAM descriptor**, map logical page+current generation to correct payload-only 4/8/16KiB physical extent, independently verify original digest at READ, CRC32C, LZ4 block length, complete 4096 owned output. Original RAW is full uncompressed 4096 and must never decode as compressed.
- Do not confuse zswap producer slot `swp_entry_t.val`, DM logical swap page, source pool object identity and consumer `gc_epoch`: each has different generation and ownership domain. Bridge mapping must be explicit source-verified (no cast, no guessed equality). Consumer ACK only after true lower I/O and authoritative publication; one matching upper ACK, no stale generation on overwrite/GC/DISCARD/reissued/slotted fault/teardown.
- **Independent evidence level:** synthetic source fixtures may demonstrate that preexisting producer snapshots can be adapted to the consumer through an explicitly checked, owned adapter and decode full 4096, with mutation tests. That is still `SOURCE_ONLY`, **not** loaded kernel, DMA, swapoff, physical header, nor actual live compressed handoff. If any field cannot be sourced authentically, negative/provisional stub is correct rather than asserting positive.

## Exact errors, concurrency and negative matrix

Keep no outstanding unbounded allocations or per-page SHA cost on hot production path until measured.
