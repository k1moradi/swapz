## Required storage semantics

Small CONFIGURABLE zswap compressed-RAM cache retains useful swap pages until legitimate Linux eviction, with NO separate swapz memory-pressure/reclaim loop. zswap RAM hit returns original 4096 via zswap's decoder. Ordinary swapout not retained in zswap uses current swapz fast LZ4/delta64/SHUF8 or existing RAW ORIGINAL UNCOMPRESSED 4096 fallback. At authentic later stored LZ4 zswap eviction, desired future optimization is transfer EXISTING compressed LZ4 block bytes length 1..3568 with no decompression/recompression using safe RAW lower-I/O machinery but separate RAM-only ZSWAP_COMPRESSED_LZ4_V1 record; current RAW must NEVER be reinterpreted as compressed. Disk-backed READ returns exact original 4096 uncompressed via codec-at-store-time and independently verified original page. Wrong codec, ZSTD, unknown slot/generation or failed ownership uses original 4096 WRITE fallback.

Existing physical backing is valid SWAPSPACE2 partition, first original 4096-byte header/UUID/signature and partition table immutable. No physical reformat, header/record magic/codec/CRC on-media. After separately owner-approved swapoff+exclusive admission only post-header data area writable. Physical 4/8/16KiB payload+zero padding only, all codec/CRC32C/slot/DM generation/GC/allocator indexes bounded volatile RAM. CRC32C producer is precisely ~crc32c(~0U,payload,len), not IEEE CRC32 or crc32c(0,..); independent original SHA256 over full 4096. Normal Linux upper BIO remains original full 4096. Only compiled/disabled source probes may be modified this round.
