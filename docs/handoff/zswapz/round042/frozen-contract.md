2. **swapz** alone owns valid already-formatted SWAPSPACE2 disk-tier ordinary writes, postheader compressed LZ4 extent packing (4/8/16KiB), bounded same-boot RAM map/GC, ordinary reads, and first-failure safety. **RAW_4096 means ORIGINAL, fully UNCOMPRESSED 4096 bytes**. Never treat compressed zswap bytes as ordinary RAW_4096 or change on-disk format.
3. Pinned original Linux mm/zswap.c zswap_writeback_entry validates the locked swapcache folio and current xarray stored entry, decompresses to the folio, erases and frees compressed entry, then starts ordinary __swap_writeout / swap_write_submit. Byte ownership alone does not create allocation/DM admission. Phase A MUST prove actual stored writeback MM→BIO→DM first and remain observational until separately approved.
4. Never mutate a physical swap partition's **entire first 4096-byte** SWAPSPACE2 header/signature/UUID or partition table. Only afterheader extents, deterministic zeros; metadata bounded volatile RAM only; no new persistent disk schema/crash-resume promises.
