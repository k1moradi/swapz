## Source-verified upstream producer and the only existing ordinary writeback

[Original upstream `mm/zswap.c`](https://github.com/torvalds/linux/blob/c339f4010dea8b0d754f84ace70cd1b089878ef8/mm/zswap.c) lines ~994–1095: `zswap_writeback_entry(entry, swpentry)` gets swap device; allocates a swapcache folio with `__swap_cache_alloc_folio`; relies on the locked folio to prevent slot reuse and swapoff; compares `entry == xa_load(swap_zswap_tree(swpentry), swp_offset(swpentry))`; calls `zswap_decompress(entry, folio)`; then `xa_erase` and `zswap_entry_free`, marks full folio uptodate and submits `__swap_writeout(&ctx, folio)` / `swap_write_submit(&ctx)`. The caller's conventional 4096-byte swap WRITE is therefore already **uncompressed**. Source lines ~1121–1202 `shrink_memcg_cb` works in the kernel's own zswap LRU/shrinker context, extracts `entry->swpentry` before dropping LRU lock and revalidates XArray later; ~1203–1230 `zswap_shrinker_scan` respects MM/memcg writeback, and ~1642–1694 `zswap_load` decompresses to swapcache, erases old zswap entry. These facts support keeping Linux MM/zswap as the **sole** compressed-RAM residency and natural-pressure eviction owner. There is **no source-authenticated compressed descriptor** passed to the ordinary downstream DM BIO here.

**Producer ownership GAP (UNPROVEN):** A hypothetical opaque export must tap upstream *before* `zswap_decompress` and before `xa_erase/zswap_entry_free`, under original kernel source-valid slot, generation, zpool handle and pool compressor reference. Merely observing an entry address or checking source flags after releasing a lifetime lock does **not** make its compressed bytes valid. An atomic or spinlock-held region cannot perform sleepable lower IO, unbounded kmalloc/retry or expensive digest/decompression. Copy at most the actual compressed length into a bounded independently owned ticket while the original zpool data is pinned and lock state is provably safe; transfer the ticket to a backpressure-bounded worker **after** releasing original locks. No such safe, authenticated export is proven or wired today. Ordinary full-page fallback is allowed only while a valid locked 4096-byte original folio still exists, never after losing original byte ownership.

- **Important incompatible legacy interface:** [Product `zswap-direct-handoff.h`](https://github.com/k1moradi/swapz/blob/28e4c2177ac8e247f3e76fd859b22ba4b026a303/src/kernel/zswap-direct-handoff.h), Git blob `864abf9a12071b98f5c157a44f4ed0c04d4a594c`, defines `SWAPZ_DIRECT_ZSWAP_LZ4=1` and `SWAPZ_DIRECT_ZSWAP_ZSTD=2` (not original LZO1X); [original-import code](https://github.com/k1moradi/swapz/blob/28e4c2177ac8e247f3e76fd859b22ba4b026a303/src/kernel/zswap-import-codec.h) defines codec2=LZO1X. **Codec value 2 would be misinterpreted if the two dormant enums were cast or reused.** This requires an explicit original-producer-authenticated translation/ABI version and unsupported-codec refusal, **not** a silent reinterpretation, API rename or automatic activation.
- [Product disk `codec.h`](https://github.com/k1moradi/swapz/blob/28e4c2177ac8e247f3e76fd859b22ba4b026a303/src/kernel/codec.h), Git blob `e89d316b9cf49f82df0b77648c1be1731607987d`, has disk encoding LZ4/delta64/shuffle and `SWAPZ_BLOCK_BYTES=4096`, `SWAPZ_MAX_BLOCKS=4`, `SWAPZ_MAX_COMPRESSED=3568` for relevant current paths. An original compressed byte stream is neither this disk encoding nor ordinary `RAW_4096`. **RAW_4096 must always contain the full original UNCOMPRESSED 4096-byte page.** A future separate `ORIGINAL_COMPRESSED_OPAQUE` representation needs explicit length/codec/version provenance and may not assume the disk max-length threshold accepts every genuine original zswap stream.

**Feasibility decision:** exact zero-recompression original-compressed transfer is **not currently possible via an unchanged conventional Linux swap BIO/DM interface** (SOURCE-VERIFIED). A separately designed and proven original-kernel producer plus typed, authenticated sideband is a **design hypothesis (UNPROVEN)**, not evidence of current functionality or of an authorized kernel patch. Original compressed codec ≠ swapz disk codec; neither can be inferred reliably from payload bytes or a pool name alone.
