## Native adapter boundary

Separate guarded C/H under src/kernel; no normal Kbuild entry, hooks, exported symbols, module parameter or activation. Native API uses Linux atomic_t, atomic_try_cmpxchg_relaxed, atomic_or, smp_store_release/smp_load_acquire and RCU. Build guard is NOT authorization. Owner explicitly initializes fresh preallocated 1..8192 record storage and fresh one-shot gate before publishing; no reinit/reuse while any caller can hold the gate. Gate stays alive until external producer revoke/join, including callers paused before entering RCU. Recorder itself is protected from first rcu_dereference through final copy/loss update/unlock. Stop serializes with control operations, disables, unpublishes and waits synchronize_rcu in sleepable process context without a producer-required lock. Retired recorder pointer cleared, no stale control pointer; no reopen on the same gate. External gate lifetime remains an integration obligation; pre-RCU entrant that resumes after unpublish sees NULL, not freed recorder. Owner must revoke/join actual event sources before ending an intended complete capture; stop alone does not count discarded pre-entry observations as late loss.

Append/mint use 64 API CAS attempts, bounded saturating counters (8192 slots, 65536 tokens max), sticky bitwise loss, no ring reuse, allocation, hash, formatting, I/O, logging or callback. Disabled path checks only stable gate pointer before RCU or event validation; future producers must test the gate before building/hash/copying input, not just call append after doing that work. Measure actual total path, not infer zero end-to-end overhead from the disabled adapter. One fixed 296B record, private until release publication of aligned u64 sequence (64-bit kernel targets only), then acquire seal after grace. A paused writer may reserve before another writer and publish after it; reservation sequence is not completion or wall-clock order. Reserve at real authoritative synchronization boundary, or only report supported partial order; if that is not safe, capture is incomplete. Never sort histories, fabricate ACK or backdate a digest. The owner and export are caller-serialized. Wire v2 keeps original mapping-source ID ff972661a75ca7f8c3c0458c3feb8b603c185eb8 unchanged as the existing parser contract, not an assertion that the running product equals that old source. Actual new scope and source map must be independently bound in future producer manifest. Header 104B, 296B records, footer 24B; explicit LE encoding and field allowlist retained. No raw pointer IDs, pointer hashes, device identities, payload or page dumps. Lossy sealed envelopes report loss, holes refuse seal/export, failed sinks are errors. Model only host fixture is source-linked actual adapter with C11/GCC atomics and pthread rwlock substitutes; not Linux RCU, LKMM, IRQ or native compile evidence.
