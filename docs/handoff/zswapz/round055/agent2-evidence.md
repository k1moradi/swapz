## 2. First missing bridge: pre-erase bytes to an authenticated, clone-aware accepted I/O owner

At zswap.c:202–220 stored entry holds a pool reference; pool has tfm_name, zs_pool, per-CPU acomp context, ref (154–162). At :822 the actually selected transform is allocated using pool->tfm_name. At :939–976 zswap_decompress obtains the pool, locks acomp_ctx->mutex, reads the zsmalloc object as one/two SG entries, decodes to PAGE_SIZE (length == PAGE_SIZE is raw), closes SG mapping and unlocks. At :777–794 zswap_entry_free drops zsmalloc handle/pool ref and frees entry; pool ID and entry addresses can be reused. The first usable capture window is AFTER current locked folio and xa_load equality and successful normal decompression, BEFORE xa_erase at 1058. A reviewed optional capture must copy actual compressed bytes within live zs_obj_read_sg_begin/end under appropriate source lifetime and never keep SG, handle, pool, acomp context or entry pointer. Use actual selected codec/framing/version (not pool ID or compressor name alone), compressed length/CRC32C and full original 4096 identity from decompression. If mapping/codec/scratch/bounded nonblocking reservation fails, ordinary RAW path must be unaffected. No blocking optional allocation or reclaim recursion while holding folio/SG; reserve a bounded byte budget and no new reclaim, no indefinite waiting for MM arrivals. A possible implementation can perform the copy at the existing decompression SG read rather than reopening the object, but only after successful decode and verified full-page identity is it eligible for transfer.

The repo already has a test-only predecessor: [stage-pinned-linux-zswap-composed.py:59–135](https://github.com/k1moradi/swapz/blob/31adfb7ff57cc5c061304beae749b485d093130b/tests/tools/stage-pinned-linux-zswap-composed.py#L59) swapz_round031_mm_bio_create copies selected LZ4 STORED bytes, uses test epoch/STORE SHA and owned_create; :3787–3859 moves the initial ref from ctx into single 4096 block BIO and puts an unconsumed owner on fallthrough/error. :185–243 v1 snapshot copies private bytes, checks origin, size and exact vector geometry, default refuses BIO_CLONED. :3866–4128 Round043 clone-only KUnit guard permits a separately refcounted full-clone copy witness; it is not current source or target authority. Do not duplicate these helpers, promote their test exports, or confuse copied bytes with authenticated accepted I/O.

**Pristine block boundary:** [block/bio.c:217–256](https://github.com/torvalds/linux/blob/c339f4010dea8b0d754f84ace70cd1b089878ef8/block/bio.c#L217) bio_init resets private/endio; :876–933 __bio_clone/bio_alloc_clone sets BIO_CLONED, shares bvec, copies iter, not a reviewed origin attachment; :945–956 bio_init_clone uninitializes on error. :343–381 chain uses bi_private for parent and endio, :1530–1579 bio_await overwrites both for synchronous stack completion; cannot borrow these fields. :1926–1966 split clones then changes size/advances original; :274–287 reset uninitializes and clears; :1863–1909 bio_endio chains/completes, may queue task completion. Native bio_get merely refs bio allocation (include/linux/bio.h:232–237); original inline swap_iocb is freed explicitly regardless of such external ref. Never bio_get/bio_put a manually embedded source BIO to manufacture a lifetime. Never capture arbitrary old private pointer, call container_of on target clone, or complete original BIO directly.

## 3. Happens-before / wait graph

A (hidden independently counted slot) remains rejected:
swapoff closes allocation -> cluster barrier -> try_to_unuse waits nonzero slot usage -> hidden external callback must release -> if callback needs swapoff/dtr or never scheduled, no owner is enumerable before unuse. Original x86 area ref kill after unuse cannot fix cycle. A real independent-count design would require registration/close/drain before try_to_unuse and interrupted-reopen integration; see Round054.

B (native accepted writeback, bounded snapshot) candidate:
locked current folio + source xa identity -> optional immutable byte copy while STORED owned -> erase/free STORED -> PG_writeback set -> unlock -> ordinary full 4096 BIO with optional attachment -> DM real full-clone admission -> current target ordered owner + lower request + current map/GC ownership -> durable lower completion and exactly one mapping -> release private request resources -> one genuine clone bio_endio -> core pending/chain completion -> original end_swap_bio_write -> folio_end_writeback -> native cache removal/slot release may occur. Source-slot identity protection ends no later than clear PG_writeback; no use of source pointers or count after terminal. Readable disk record must be independently owned by current DM map, not by snapshot or zswap pool.

Native swapoff at mm/swapfile.c:3231–3249 closes allocation under locks then releases both, waits allocator barrier, try_to_unuse. :2886–2925 takes folio lock then waits writeback, attempts cache release, retries while counted usage; :3259–3286 kills area users and destroys area only after unuse. **The target worker/lower callback must never acquire that folio lock, need new MM evictions, wait for swapoff, wait for dtr, or wait on a lock held by the unuse waiter.** Native completion itself clears PG_writeback before dropbehind's later lock (filemap.c:1710–1715). All optional digest/codec validation in bounded worker context, no sleep in map and no target lock across upper bio_endio. A bounded independent lower service can complete existing writeback without registering a new swap count. If not independently runnable, reject B too. Normal DM suspend :2987–3040 blocks new I/O, SRCU barrier, flush work, waits pending I/O before suspended/table swap (:2879–2890); product postsuspend/drain closes admission after that wait. Do not depend on postsuspend/dtr to finish already pending IO, or on a future retention deadline with no guaranteed worker. Forced removal/immediate destruction is outside supported scope.

## 4. Decision and smallest reviewed next implementation

| Situation | B feasibility / required disposition |
| --- | --- |
| Valid current STORED copy tied to same live original full-page BIO, same accepted full target clone, no new count, valid native writeback and independently runnable lower | Conditionally feasible *lifetime design*, not proven actual end-to-end. Native cache pin and area lifetime already serve normal IO. Still require reviewed attachment and actual target authorization, no separate slot put. |
| Unsupported codec/version, raw PAGE_SIZE stored, size/geometry mismatch, non-4096 architecture, capacity/check failure or absent metadata | Drop snapshot; preserve native full original RAW_4096. Codec-aware reader must not depend on pool lifetime, CPU-selected transform or ephemeral pointer. Compare decoded full-page bytes/SHA against original BIO, not assume writeback flag proves byte immutability. |
| Before submission: no block BIO, failed decode, reservation failure, never-dispatched optional work | Source/ctx owns initial copy until explicit move. On any no-move exit destroy exactly once; do NOT defer source ownership or skip mandatory original IO. A queued but unused optional copy is disposable; a real accepted upper BIO still must get normal completion/error. |
| Clone creation fails; split/trim, generic propagation, DM queue/requeue, target generation replacement, interrupted suspend or swapoff EINTR/reinsert | Invalidate eligibility and release each actual attachment ref once; normal full-page original path survives. Requeue can preserve an original BIO without old target ownership, so default RAW on every reissue until fully reauthenticated. Reopen is not reuse of old transaction/slot identity. |
| Lower failure, ENOSPC, GC conflict or teardown | Never publish new map before actual durable write; unwind staged allocation, old committed map and previous valid record unchanged. Raw retry only while genuine accepted BIO still owns original full page; else complete error once, original swap_write_end redirties. Cancel unsent target work inline or via independent worker, not dtr/unuse. |
| Late/duplicate callback after terminal or after original writeback ended | No source slot/folio/area/clone/private lookup; one terminal claimant and release, retired callback object freed only after actual lower callback quiescence. No hidden ref/late put. |
| Successful ACK | Must first have actual owned current target/map/GC lifetime, exact codec-aware durable lower data and one authoritative map. Complete accepted clone once, native core propagates only actual original terminal completion; no claim of success from a copied callback count. Decoder contract and any decoder-module lifetime must remain pinned by the authoritative RAM map through GC/read/retirement independently of zswap. Verify real read full original 4096 and SHA; reject unrecognized codec or integrity failure. |

Minimal future work in order (review/approval required): (1) design bounded non-sleeping optional ownership transfer before STORED retire, held exactly by original I/O and explicit full-view clone lifetime, with source allocation-incarnation identity proved by native protection rather than copied epoch. (2) block/DM in-core propagation and invalidation, no private/endio hijack, checked current target-relative sector; accepted target claims snapshot only under existing ordered admission, with no extra lifetime beyond ordinary BIO. (3) stable independent disk decoder descriptor and GC/read/drop lifetimes; retain full RAW fallback and byte/CRC/SHA evidence; define durability including lower device write cache/FUA/flush, not assume ordinary completion is persistence. (4) actual rootless original core + DM end-to-end ownership/fault test with genuine clone completion, retry, no-dispatch, reissue and ordinary fallback before any opt-in. Candidate fails if it needs independent count, producer waits for unuse, real target lease unproven or decoder not stable. No new source or fixture solely to pad refusal count. Existing test-only clone refusal and v1 boundaries are deliberate; no new reproducible source defect identified in the owned path by this review. No new runtime tests claimed.
