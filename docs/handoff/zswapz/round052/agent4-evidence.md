# Round052 Agent4 — actual selected zswap compressor versus product swapz codec (NO AUTH)

## Read-only original-source evidence

The exact original Linux baseline is `torvalds/linux@c339f4010dea8b0d754f84ace70cd1b089878ef8`, **not** the host kernel. Its `mm/zswap.c` lines 100–110 make `zswap_compressor` a **runtime-writable** module parameter initialized from `CONFIG_ZSWAP_COMPRESSOR_DEFAULT`. Its `mm/Kconfig` defaults that selection to **LZO**, not LZ4. A pool separately copies the selected name into `pool->tfm_name` (zswap.c around line 316), then each CPU allocates `crypto_alloc_acomp_node(pool->tfm_name,...)` (around 822). `zswap_compress` passes a full `PAGE_SIZE` source to `crypto_acomp_compress`, stores `req->dlen`, and uses uncompressed `PAGE_SIZE` entries when compression does not fit (around 856–936). `zswap_decompress` checks length `==PAGE_SIZE` for uncompressed copies and calls the **same pool**'s `crypto_acomp_decompress` otherwise (around 939–987); `zswap_writeback_entry` creates and writes a full uncompressed folio (around 994–1080). Runtime active pool identity/codec cannot be inferred from compile-time default or from the substring "LZ4".

The original pinned `crypto/lz4.c::__lz4_compress_crypto` directly calls kernel `LZ4_compress_default(src,dst,slen,*dlen,ctx)` and updates `*dlen` to the raw block result. Its matching decompress calls `LZ4_decompress_safe(src,dst,slen,*dlen)`. `crypto/acompress.c` adapts synchronous `crypto_scomp` implementations to acomp; crypto algorithm *name* selection remains variable. Original LZ4 produces raw blocks, no LZ4 frame header, external dictionary or per-block CRC in that C wrapper; the current runtime-selected pool may be different. The new verifier extracts and compiles the *unmodified actual pinned original C wrapper* but deliberately bridges its kernel five-argument compression call to **userspace liblz4**, and thus reports **HOST_RAW_LZ4_SUBSET, not an original loaded-kernel byte proof**.

## Actual swapz product decoder and transport contract

Current `src/kernel/codec.h` defines `SWAPZ_MAX_COMPRESSED=3568`, flags `LZ4=0`, `DELTA64=1`, `DELTA64_SHUF8=2`, and `SWAPZ_CODEC_METADATA_ON_MEDIA=0`. `src/kernel/codec.c` validates encoded compressed lengths and encoding, calculates **CRC32C over compressed payload**, keeps bounded `swapz_decoded` descriptors in volatile RAM, and `swapz_ram_extent_seal` zero-pads **payload-only** 4/8/16KiB lower extents. Its actual `swapz_ram_extent_read` verifies size, ownership-supplied logical/generation, offset, encoding and compressed CRC. Actual `src/kernel/dm-target.c` LZ4 decoder uses `LZ4_decompress_safe` directly for `SWAPZ_ENCODING_LZ4` and must obtain **exactly 4096** decoded bytes; delta64/shuf8 encoded records must pass separate inverse predictor transforms, not be passed as native zswap STORED bytes. A full **original page** SHA256 and byte-for-byte comparison are additional conservative requirements on any hypothetical lower reuse; compressed CRC alone does not authenticate the full decoded source page.
