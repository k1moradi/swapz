- **Current accepted BIO:** `swapz_map` validates target-relative 8-sector page indexes, initializes `dm_per_bio_data` anew on each invocation, then inserts accepted descriptors under `queue_lock` and returns `DM_MAPIO_SUBMITTED`. A closed admission checks `accepting` under the same lock and returns `DM_MAPIO_REQUEUE` or `DM_MAPIO_KILL` without publishing an incoming descriptor. These are DM callback-scoped ownership facts, **not** original zswap folio or original BIO lifetime.
- **Normal RAW:** `swapz_raw_write` copies the upper BIO's **original uncompressed full 4096 bytes** to `ctx->input_page` before RAW stage/lower write/authority publication. Nothing here imports original LZO1X/LZ4 STORED bytes as ordinary RAW. `src/kernel/zswap-import-admission.h` and `zswap-import-codec.h` retain `SWAPZ_ZSWAP_IMPORT_ADMISSION_ACTIVE 0U` and `SWAPZ_ZSWAP_IMPORT_ACTIVE 0U`.
- **Completion:** the ordered owner calls `swapz_complete`, which checks terminal failure, releases prepared slots **before** actual `bio_endio`, and never accesses the released per-BIO data afterward. Real `swapz_end_io` preserves an existing error or forces an error if the target has become terminally failed. Existing source does not prove an independently imported, real original STORED upper ACK exactly once.
- **Suspend/teardown:** `swapz_drain` closes admission under `queue_lock`, cancels the retention timer, waits submitter preparation, producer/ordered queues and lower completions, and diagnoses residual ownership before `swapz_dtr` frees the context. This is bounded code-path inspection, **not** an actually executed table reload, inflight reissue, lower I/O or teardown workload.
