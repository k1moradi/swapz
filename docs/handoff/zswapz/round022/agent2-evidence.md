## Exact upstream source and known execution boundary

The pinned `zswap_store_page()` stores compressed bytes in zsmalloc and publishes an entry into the swap-slot xarray, pins pool/object accounting, records the swap entry and inserts into LRU while the folio lock excludes concurrent store/invalidation. The zswap shrinker gives referenced pages a second chance; the genuine eviction branch drops the LRU lock, obtains a locked swap-cache folio, and rejects a recycled xarray entry by pointer identity. The **currently compiled path** calls `zswap_decompress()` to recover full `PAGE_SIZE` bytes, erases/releases the old entry, sets the *already-decompressed* origin tag, and submits ordinary `REQ_OP_WRITE | REQ_SWAP`. The original raw BIO remains a full original 4096-byte page. No compressed payload is submitted via that BIO.

The **compile-disabled** `COMPRESSED_HANDOFF_SOURCE` has been tightened as a proposed, distinct volatile-RAM producer v1 contract: `ZSWAP_SWAPZ_REPR_ZSWAP_LZ4_V1` (not `RAW_4096`), representation version 1, only store-time verified LZ4, bounded payload size 1..3568, original length 4096, swap-slot identity plus nonzero generation/epoch, pinned xarray entry identity, and store-time full original SHA256. A source-only binding helper accepts a pointer to original 4096 bytes while the folio is locked and explicitly computes SHA256 on the **original**, never on zsmalloc payload. A later capture checks identity, generation, recorded store codec against retained pool codec, creates a separate owned `kmalloc` allocation, copies the exact compressed bytes synchronously while original zpool scatterlist is mapped, closes the borrow, and computes **CRC32C**, not the incompatible previous CRC32. The immutable descriptor snapshots generation, SHA, codec, length, representation, owned pointer, CRC32C and source provenance before the one-way atomic submission transition.

`submit` checks self-identity (rejects shallow clone), owned pointer, LZ4 v1, positive generation, nonzero independent SHA, size and CRC32C; invalid snapshots return to OWNED without a submission. `abort` can release only OWNED, `finish` only SUBMITTED, and a failed asynchronous completion retains its negative cause and releases allocation only once. Callback and producer state stay owned until quiescent. Old or replaced slots, missing SHA, unsupported ZSTD/unknown/changed codec, wrong generation, failed allocation and >3568 payloads are refused; the existing *compiled* decompress-to-original fallback remains unchanged because this entire transport block is behind `#if 0`. Compression/reclamation policy, on-media extent layout, partition header, RAW handling and DM code were not modified.

**Unresolved integration authority**: a real live binder at `zswap_store_page()`, authoritative swap-slot generation/epoch from the kernel, store-time digest/per-page memory/CPU budgets, bounded concurrent outstanding proofs, actual transport ABI through clone/split/reissue, consumer decoder, lower durable completion and loaded original readback remain unimplemented/not authenticated. A caller-provided mock proof is **never** evidence of genuine stored-entry eviction; the independent SHA is calculated by a host stand-in for the known original page, not a real kernel crypto invocation. A future integration must independently prove locking/entry generation and benchmark a 4096-byte SHA per stored page plus a small proof descriptor and up to 3568 bytes immutable payload per outstanding handoff. Do not enable this source-only prototype.
