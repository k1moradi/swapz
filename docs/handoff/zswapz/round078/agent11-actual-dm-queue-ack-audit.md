## 2. Producer / current owner / consumer transfer

```text
DM core clone BIO (external clone/target lifetime)
  |
  +-- swapz_map(): accepting false, bad shape/op
  |      -> DM_MAPIO_REQUEUE or DM_MAPIO_KILL; target never owns incoming
  |
  +-- swapz_map(): initialize dm_per_bio_data, queue_lock
         -> incoming.append(entry), optional preparation_incoming append
         -> DM_MAPIO_SUBMITTED = target now owes terminal completion
              |
              +-- optional bounded preparation worker / submitter
              |      -> take preparation descriptor under queue_lock
              |      -> copy unchanged full original 4096 input snapshot
              |      -> optional swapz DISK codec (ordinary page only)
              |      -> ready + release owner ref; NO map, NO lower ACK
              |
              +-- ordered worker / rare owned submitter-dispatch
                     -> mutex ordered_owner BEFORE queue_lock
                     -> splice incoming to FIFO local, finite 64 serviced
                     -> stage <= max_window <= SWAPZ_MAX_RECORDS
                     -> bulk sync lower or single async inflight slot
                     -> lower success + required FUA/flush
                     -> authority map publication or rollback
                     -> release prepared reference before endio
                     -> swapz_complete() exactly once by intended owner
                        OR successful-deferred cohort -> completion_work()
                     -> bio_endio; never dereference entry again
  |
  +-- DM clone ->end_io observes resulting error, does NOT re-complete
  |
  +-- suspend/dtr: close accepting under queue_lock -> drain accepted work
```

Transfer synchronization: `ordered_owner` is acquired before `queue_lock`; map never mutex-locks while holding the spinlock (only an optional non-sleeping `mutex_trylock` **before** it). Inside `queue_lock`: no `wait_for_completion`, no lower synchronous `dm_io`, no compression, no allocations or long SHA. Producer slot claim/free-mask is atomic; producer work and `swapz_process` do slow snapshot, LZ4, GC and lower I/O **outside** the lock. The callback takes `queue_lock`, elects terminal failure before `complete(lower_done)`, and wakes worker; it does not own upper endio. [`dm-target.c:760-777`](https://github.com/k1moradi/swapz/blob/9a1cc39bf0f191093ef98857510fb6475778d2fc/src/kernel/dm-target.c#L760-L777) [`dm-target.c:2853-2906`](https://github.com/k1moradi/swapz/blob/9a1cc39bf0f191093ef98857510fb6475778d2fc/src/kernel/dm-target.c#L2853-L2906) [`dm-target.c:8193-8265`](https://github.com/k1moradi/swapz/blob/9a1cc39bf0f191093ef98857510fb6475778d2fc/src/kernel/dm-target.c#L8193-L8265) [`dm-target.c:8418-8520`](https://github.com/k1moradi/swapz/blob/9a1cc39bf0f191093ef98857510fb6475778d2fc/src/kernel/dm-target.c#L8418-L8520) [`dm-target.c:14100-14171`](https://github.com/k1moradi/swapz/blob/9a1cc39bf0f191093ef98857510fb6475778d2fc/src/kernel/dm-target.c#L14100-L14171).

The accepted ordinary clone's `bio` pointer is valid **while that specific DM-clone is still owned**; preparation work accesses it until `preparation_snapshot_ready`, the ordered worker may use it again for RAW re-copy after GC, and it becomes invalid for per-BIO dereference once `swapz_complete` invokes `bio_endio`. The source explicitly guards this use-after-complete boundary in `swapz_release_prepared`, `swapz_worker_pass` and owned submitter dispatch. [`dm-target.c:583-618`](https://github.com/k1moradi/swapz/blob/9a1cc39bf0f191093ef98857510fb6475778d2fc/src/kernel/dm-target.c#L583-L618) [`dm-target.c:1830-1870`](https://github.com/k1moradi/swapz/blob/9a1cc39bf0f191093ef98857510fb6475778d2fc/src/kernel/dm-target.c#L1830-L1870) [`dm-target.c:10229-10263`](https://github.com/k1moradi/swapz/blob/9a1cc39bf0f191093ef98857510fb6475778d2fc/src/kernel/dm-target.c#L10229-L10263) [`dm-target.c:12855-12889`](https://github.com/k1moradi/swapz/blob/9a1cc39bf0f191093ef98857510fb6475778d2fc/src/kernel/dm-target.c#L12855-L12889) [`dm-target.c:13210-13270`](https://github.com/k1moradi/swapz/blob/9a1cc39bf0f191093ef98857510fb6475778d2fc/src/kernel/dm-target.c#L13210-L13270). A host-owned ticket, a model counter and a compiler-positive test cannot stand in for this DM lifetime.
