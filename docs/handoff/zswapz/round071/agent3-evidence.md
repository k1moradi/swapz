## Original source-bound lifetime and first missing prerequisite

The genuine original `zswap_store()` warns unless the source folio is locked **and** swapcache-backed; `zswap_store_page()` compresses into zsmalloc, sets `pool_idx` before `xa_store`, replaces the old entry, obtains pool/objcg refs, and initializes the entry before adding it to the reclaim LRU. Its comment explicitly relies on the *real folio lock* excluding concurrent stores/invalidation while the new XArray object is partially published. The original `shrink_memcg_cb()` copies only `swpentry` before dropping its LRU lock because the entry pointer may immediately become stale; dereferencing is permitted again only after `zswap_writeback_entry()` obtains the swap-device reference via `get_swap_device(swpentry)`, allocates a **real** swapcache folio with `__swap_cache_alloc_folio()`, and rechecks `entry == xa_load(tree, offset)` under the locked folio. Successful original writeback calls `zswap_decompress()`, erases/frees the original compressed entry, and then issues the conventional **uncompressed** swap BIO. `zswap_load()` similarly erases/frees the entry after reconstructing the swapcache folio.

For a hypothetical compressed passthrough, the only safe pre-erase copy boundary would require an authenticated current swap type/offset and incarnation, the **actual selected STORED** entry, a locked genuine swapcache folio and slot lifetime, valid pinned pool/codec lease, and an owned bounded copy completed **before** XArray erase/entry free. An arbitrary same-value swap entry, synthetic XArray, manually allocated locked folio, or user-supplied epoch/identity cannot provide those capabilities. The first nonmock prerequisite missing from this rootless fixture is a live and retained original `get_swap_device()`/`__swap_cache_alloc_folio()` source tied to an authorized active swap slot and selected production mapping. Creating one would require swapon/device activation or another independently authorized integration resource and is **not** attempted.
