## zswap–swapz scheduling and compressed-payload roadmap

User's explicit optimization: **preserve compressed zswap RAM pages when backing swapz writeback is necessary, avoiding zswap decompression followed by swapz recompression**. Existing swapz `RAW` denotes **uncompressed full 4096-byte logical pages**. Writing opaque zswap compressed bytes through the current RAW path would be incorrect: normal backing swap-in needs a byte-exact logical 4096-byte page, and zswap's compressor may be ZSTD/LZ4 and not swapz's existing encoding.
