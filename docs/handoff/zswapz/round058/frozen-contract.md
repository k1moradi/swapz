## Architectural objective and hard limits

Native Linux memory management alone decides when previously STORED zswap pages leave compressed RAM under memory pressure. Swapz is a DISK-only payload compressor, 4/8/16 KiB packer and ordered GC; **no competing shrinker, forced drain, recompression of already verified source compressed bytes, or wait on future MM memory relief**. The potential zero-recompression transport is a **new separately tagged volatile imported-compressed record carried in a protected disk payload**, never ordinary `RAW_4096` (which is always the complete ORIGINAL **UNCOMPRESSED 4096 bytes**). The original zswap codec and swapz disk codec are distinct; the reader must dispatch only the original selected source codec and retain decoder ownership beyond retirement of the zswap pool. Chosen source LZ4 is only host/source-subset qualified; original default LZO profile is corrected in Round057 but final exact decoder/profile CI was still queued. Unknown codec/version/format, dictionary, >3568 compressed bytes, mismatched original SHA256, CRC, truncated/trailing input or retired source/decoder must reject optional compressed admission and preserve native full-page writeback before commitment. Postcommit imported read corruption is an explicit error, never RAW fallback.

The only potentially authentic source must be a genuine originally STORED zswap entry with locked current folio/xarray identity, decoded full 4096 SHA, bounded nonblocking immutable pre-erase compressed snapshot; preserve single lifetime through original MM→BIO→actual full clone/accepted current target, not merely copied scalar metadata or ticket ref. Explicitly handle original BIO init/reset/split/trim/advance/requeue/endio/reuse, bvec and bdev ownership, target-relative 8 sectors, native source / current DM table dtr, post-teardown callback, and close both source and target leases. Never bio_get the original embedded swap_iocb or hijack core bi_private/endio. Failed/unverified paths default UNKNOWN, no missing or duplicate 4 KiB writeback attribution.

For optional future imported lower storage, prove real ordered lower WRITE plus flush/FUA durability (not modeled callback), then exactly one authoritative current volatile imported descriptor/map entry, exactly one genuine kernel upper ACK only on success, later full original 4096 byte-exact codec-correct read under GC/read pins and decoder ref. Production 20-byte normal map must remain intact; do not guess spare tags or introduce persistent metadata. Preserve **entire first physical 4096 SWAPSPACE2 header, UUID, signature and parent partition table**. No physical experiment, loaded module, actual swap pressure, privilege or owner `make test`/`make fast_test` permission. All output remains rootless, test-only/default-UNDEFINED or observational, without production activation.
